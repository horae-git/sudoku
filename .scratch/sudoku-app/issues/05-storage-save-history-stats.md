# 05: 存檔 / 遊玩紀錄 / 生涯統計 storage

**What to build:** 實作 JSON storage（存於使用者資料目錄）：(1) 自動存檔——每次動作與每秒計時觸發、原子寫入（先寫 tmp 再 rename），每個模式（簡單/中等/困難/專家/每日挑戰）各保留一份進行中存檔，重開 app 可繼續；(2) 遊玩紀錄——歷史清單，可依難度與結果（完成/放棄）篩選；(3) 生涯總覽——各難度最佳時間、零錯誤完成次數、每日挑戰連勝（當天完成才算一天）。放棄的局：留歷史標「放棄」、清掉該局存檔。

**Blocked by:** 01 專案骨架與核心領域模型

**Status:** ready-for-agent

- [ ] 統計：各難度最佳時間、零錯誤次數、每日挑戰連勝
