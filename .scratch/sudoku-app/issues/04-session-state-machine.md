# 04: 對局狀態機（Session）

**What to build:** 實作對局狀態機，集中管理一局的所有規則：填入（題示數不可改）、錯誤（填錯立即標紅、計次、不設上限、紅色保留至修改）、提示（每局 3 次、綠色且鎖定）、筆記（填入正確數字後自動清除同行/列/宮相同數的筆記）、復原（完整動作堆疊可一路回開局，含提示）、暫停（計時停止）、計時（開始自動計、完成停止）、勝利判定（填滿且全正確）。此為純邏輯層，UI 只訂閱其狀態。

**Blocked by:** 03 技巧鏈求解器與四級難度分級

**Status:** ready-for-agent

- [ ] 填入/清除/錯誤判定與計次正確
- [ ] 提示 3 次、綠色鎖定不可改
- [ ] 筆記新增/自動清除衝突候選數
- [ ] 復原可一路回開局（含提示格）
- [ ] 暫停時計時停止、完成時計時停止且判定勝利
- [ ] pytest 測試上述所有行為（只測外部行為）
