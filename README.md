# README — 數獨遊戲

本專案的領域術語統一用語。不含實作細節；決策見 `docs/adr/`。

## 核心概念

- **題目（Puzzle）**：一個 9×9、部分格子已填的數獨盤面。生成時保證**唯一解**。
- **解答（Solution）**：題目的唯一完整解。
- **格子（Cell）**：棋盤上第 r 列 c 行的單位，可為空、固定題示數、玩家填入數、提示填入數。
- **宮（Box）**：3×3 的九宮格區塊，共 9 個。

## 難度（Difficulty）

難度由兩個維度共同決定（見 PRD）：

1. **技巧深度**：以技巧鏈求解器解題時，所需的**最難技巧等級**（naked/hidden singles → pairs → locked candidates → X-wing → swordfish …）。
2. **挖空數**：從完整解答中挖去的格子數量。

| 難度           | 定義                                     |
| -------------- | ---------------------------------------- |
| 簡單（Easy）   | 只需 single（naked/hidden）即可解        |
| 中等（Medium） | 需要 pair / locked candidates 等中階技巧 |
| 困難（Hard）   | 需要 X-wing 等高階技巧                   |
| 專家（Expert） | 需要 swordfish / 更高階技巧              |

## 遊戲狀態

- **進行中（InProgress）**：計時中、可填入、可暫停的對局。
- **已完成（Completed）**：填滿且全部正確的對局，計時停止。
- **已放棄（Abandoned）**：玩家主動結束但未完成的對局，計入歷史但不計最佳時間。
- **每日挑戰（DailyChallenge）**：以日期字串為種子生成的固定題目（難度固定中等），每天同一道；完成即為當日連勝一天。

## 玩家動作

- **填入（Place）**：在空格填入 1–9。
- **清除（Clear）**：清空玩家填入的格子（題示數不可清除）。
- **提示（Hint）**：每局 3 次，隨機填入一個正確格子，綠色且鎖定。
- **筆記（Note）**：在空格記錄候選數字（3×3 小字），不影響答案判定。
- **復原（Undo）**：Ctrl+Z / ↩，完整動作堆疊，可一路復原到開局。
- **暫停（Pause）**：Esc / ⏸，棋盤以半透明遮罩覆蓋，計時暫停。

## 判定

- **錯誤（Mistake）**：填入與解答不符。立即標紅、計次，紅色保留直到玩家修改；不設上限，不結束本局。

## 記錄

- **遊玩紀錄（History）**：歷史清單，可依難度與結果（完成/放棄）篩選。
- **生涯總覽（Stats）**：各難度最佳時間、零錯誤完成次數、每日挑戰連勝天數。
- **存檔（Save）**：每次動作與每秒計時自動原子寫入的進行中對局，重開 app 可續玩。**已知限制**：續玩還原的局 undo 堆疊為空（存檔不保存動作堆疊），無法一路復原回開局，只能在續玩後繼續復原當前局的動作。

## 視覺

- **主題（Theme）**：一份色票（背景、格線、選取、錯誤紅、提示綠等）。內建 3 套：淺色 / 深色 / 馬卡龍。深色主題下九宮格粗線更明顯。
