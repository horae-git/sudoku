# 06: 主選單與棋盤 UI（選取 / 高亮 / 填入 / 錯誤 / 鍵盤）

**What to build:** 打造主選單畫面（每日挑戰、四難度開始、遊玩紀錄、生涯總覽、🎨 主題按鈕置於顯眼處）與棋盤畫面：9×9 格子繪製（宮粗線）、點選選取格、同行/列/宮及相同數字自動高亮、滑鼠填入、填錯立即紅色顯示、完整鍵盤操作（方向鍵移動、1–9 填入、Delete/Backspace 清除）。視覺為現代扁平、按鈕與線條圓角。可端到端示範：開新局 → 選格 → 填入 → 錯誤標紅。

**Blocked by:** 02 MRV + 回溯題目生成、03 技巧鏈求解器與難度分級、05 存檔/紀錄/統計 storage
