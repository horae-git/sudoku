# 07: 遊戲畫面完整流程（計時 / 提示 / 筆記 UI / 暫停遮罩 / 自動存檔 / 每日挑戰標示）

**What to build:** 把遊戲畫面補完為可完整遊玩的流程：右側資訊面板顯示計時器（開始自動計時、完成停止）、錯誤次數、剩餘提示次數；筆記模式按鈕 + N 鍵切換，格內顯示 3×3 候選小字；⏸ 按鈕或 Esc 暫停時棋盤覆半透明遮罩＋置中「⏸ 已暫停」且計時停止；↩ 按鈕或 Ctrl+Z 復原；每次動作與每秒計時自動存檔、重開可續玩；每日挑戰局標示「本日題目」；放棄回首頁時記為放棄。可端到端示範一整局。

**Blocked by:** 04 對局狀態機、06 主選單與棋盤 UI

**Status:** ready-for-agent

- [ ] 計時器自動開始、完成停止；面板顯示用時/錯誤/提示數
- [ ] 筆記按鈕 + N 切換、候選數正確顯示與自動清除
- [ ] 暫停時遮罩蓋住棋盤且計時停止；Esc / ⏸皆可
- [ ] 復原 ↩ / Ctrl+Z 可用
- [ ] 自動存檔：每動作 + 每秒寫入、重開可繼續
- [ ] 每日挑戰局有「本日題目」標示；放棄正確記錄
