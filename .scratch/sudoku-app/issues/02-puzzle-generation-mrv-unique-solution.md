# 02: MRV + 回溯題目生成（保證唯一解）

**What to build:** 實作題目生成器：先以回溯產生完整解答，再以 MRV（最小剩餘值）啟發式選擇挖空順序挖洞，每挖一格即用計數回溯驗證唯一解，不唯一就還原。玩家選難度開局或每日挑戰（日期種子）時，能在短時間（約 1 秒內）拿到一道保證唯一解的題目。每日挑戰以日期字串為種子，同一天必為同一道題。

**Blocked by:** 01 專案骨架與核心領域模型

**Status:** ready-for-agent

- [ ] 生成任意一道題目，驗證具有唯一解
- [ ] 生成時間短（單題約 1 秒內）
- [ ] 每日挑戰同一日期種子產生同一道題、不同日期不同題
- [ ] pytest 測試：唯一解性質、種子穩定性、生成速度
